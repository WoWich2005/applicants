# Дипломный проект — LaTeX-исходники

## Тема
«Программное обеспечение для управления приёмом абитуриентов в Белорусский национальный технический университет»

## Структура

```
diploma/
├── main.tex                    # корневой документ
├── preamble.tex                # настройки шрифтов, полей, заголовков, подписей
├── Makefile                    # сборка через `make`
├── images/                     # сюда складывать рисунки (.png, .pdf)
├── reference/                  # материалы от руководителя (не входит в сборку)
└── sections/
    ├── titul.tex               # титульный лист (без номера)
    ├── zadanie.tex             # задание на ДП (с двух сторон)
    ├── referat.tex             # реферат
    ├── vedomost.tex            # ведомость объёма ДП
    ├── toc.tex                 # оглавление (нумерация начинается с 6-й стр.)
    ├── abbreviations.tex       # перечень условных обозначений
    ├── intro.tex               # ВВЕДЕНИЕ
    ├── chapter1.tex            # 1 Обзор состояния вопроса
    ├── chapter2.tex            # 2 Выбор программно-технических средств
    ├── chapter3.tex            # 3 Проектирование приложения
    ├── chapter4.tex            # 4 Программная реализация
    ├── chapter5.tex            # 5 Руководство пользователя
    ├── chapter6.tex            # 6 Тестирование приложения
    ├── chapter7.tex            # 7 Технико-экономическое обоснование (TODO: цифры)
    ├── chapter8.tex            # 8 Охрана труда
    ├── conclusion.tex          # ЗАКЛЮЧЕНИЕ
    ├── bibliography.tex        # СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ
    └── appendix.tex            # ПРИЛОЖЕНИЯ (графика, листинги)
```

## Сборка

```bash
make            # 3 прогона pdflatex для оглавления
make clean      # удалить промежуточные файлы
```

Требуется TeXLive 2022+ с пакетами: `babel-russian`, `times`, `tabularx`,
`booktabs`, `enumitem`, `titlesec`, `titletoc`, `tocloft`, `caption`,
`fancyhdr`, `hyperref`, `geometry`, `chngcntr`, `listings`, `xcolor`,
`makecell`, `anyfontsize`, `indentfirst`.

## Соответствие требованиям БНТУ (методичка 2025 г.)

- Times New Roman 14pt, межстрочный 18pt
- Поля: лево 30 мм, право 15 мм, верх/низ 20 мм
- Абзацный отступ 1.25 см
- Номера страниц в правом верхнем углу
- Нумерация с титульного листа; печатается с 6-й страницы (вторая страница оглавления)
- Заголовки разделов: ПРОПИСНЫЕ полужирный 14pt по центру, без точки
- Подзаголовки: строчные с первой прописной, полужирный
- Подписи рисунков: «Рисунок N — Название», по центру под рисунком
- Подписи таблиц: «Таблица N — Название», слева над таблицей
- Каждый раздел с новой страницы
- Источники: номер без точки после, без абзацного отступа,
  для электронных — режим и дата доступа
